## Features

- **Dual Backup Automation** – Templates for configuring both local and cloud backups simultaneously, ensuring immediate local access while maintaining an offsite copy for disaster recovery [reference:0]
- **Continuous Data Protection (CDP)** – Workflows for real-time backup of file changes, automatically recognizing and backing up modified files as soon as changes are made [reference:1]
- **Cross-Platform Sync & Cloud Drive** – Scripts for seamless file synchronization across Windows, macOS, iOS, Android, and Linux devices using IDrive Cloud Drive, with files accessible from anywhere [reference:2]
- **Image Backup & Disaster Recovery** – Presets for complete disk imaging (Windows PCs) and bare-metal recovery, enabling full system restoration [reference:3]
- **Cloud-to-Cloud Backup** – Configurations for backing up data from third-party platforms including Microsoft 365, Google Workspace, Dropbox, and Box, with up to three automated backups per day [reference:4][reference:5]
- **AI-Powered Photo Management** – Templates for IDrive People facial recognition, automatically organizing backed-up photos by detected faces with support for JPG, JPEG, PNG, HEIC, BMP, and NEF formats [reference:6]
- **Military-Grade Encryption** – Presets for AES 256-bit encryption during transfer and storage, ensuring enterprise-grade data security [reference:7]
- **Incremental & Compressed Backups** – Configurations for bandwidth-efficient backups, transferring only modified portions of files [reference:8]
- **Unlimited Device Support** – Workflows for backing up an unlimited number of devices under a single account [reference:9]
- **Cross-Platform Compatibility** – Configuration scripts for seamless workflow across Windows, macOS, iOS, Android, and Linux [reference:10]

## Requirements

- **Operating System:** Windows 10/11, macOS 10.13+, iOS, Android, or Linux
- **Internet connection** for cloud backup and sync features
- **IDrive account** (Free with 10GB, Personal, Team, or Business) – this repository is for legitimate users
- **Basic understanding** of backup and data protection concepts

## Usage

1. Download and extract the repository files.
2. Open the `/docs` folder and read the `GettingStarted.md` guide.
3. Choose your desired configuration:
   - **Scripts:** Run the backup and sync automation scripts from `/scripts`.
   - **Templates:** Import the backup schedule and encryption templates from `/templates`.
   - **Presets:** Apply the CDP, Cloud Drive, and AI photo management presets from `/presets`.
4. Launch IDrive and follow the documentation to apply your configurations.
